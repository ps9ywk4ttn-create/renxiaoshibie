# 异常处理工具 SOP

适用范围：实时人效看板里的“异常处理工具”，用于库存查询、库位查询、异常记录生成、明细查看和导出。

## 1. 启动与进入

1. 双击 `启动实时人效看板.command`。
2. 打开浏览器地址：`http://127.0.0.1:5317`。
3. 进入页面后，点击顶部的“异常处理工具”。
4. 如需使用“清除缓存”等管理功能，先切到“管理员版”。

## 2. 基础查询

### 2.1 库存查询

1. 在中间输入框“输入 SKU / 条码”里输入货品编码或货品条码。
2. 按回车，或点击“库存查询”。
3. 查询结果会显示：
   - 查询值
   - 产品图片
   - 货品名称
   - 货主名称
   - 库位
   - 可用库存
   - 占用库存
4. 查询值和货主名称旁边有复制按钮。
5. 库位旁边有复制按钮；点击库位本身，会打开二维码弹窗。
6. 可用库存、占用库存中大于 0 的数字可以点击，点击后用于后续竖版异常处理。

库存输入规则：
- 只接受英文和数字。
- 英文默认按当前输入逻辑处理大小写。
- 输入货品条码时，系统会先当货品编码查；如无结果，再按货品条码查。

### 2.2 库位查询

1. 点击右侧输入框“输入库位”。
2. 输入框默认出现 `CPE-`。
3. 输入时自动转大写，并自动按库位格式补 `-`。
4. 支持粘贴完整库位，例如 `CPE-M15-110-01`；系统会自动过滤前面的 `CPE-` 并保留后面的库位内容。
5. 按回车，或点击“库位查询”。
6. 查询结果只显示：
   - 货品编码
   - 货品条码
   - 可用库存
   - 占用库存
7. 货品编码和货品条码都可以点击；点击后会转到库存查询，等同于把该编码或条码输入到库存查询里。
8. 通过库位查询跳到库存查询时，对应库位所在行会标红，表示这个库位是当前操作的原始库位。

库位输入删除规则：
- 如果输入框里只有 `CPE-`，按删除会一次清空。
- 后续输错时，按删除按正常字符逐位删除。

## 3. 二维码与打印

### 3.1 单个库位二维码

1. 在库存查询结果表格里点击某个库位。
2. 页面中央会显示二维码弹窗。
3. 弹窗中包含：
   - 库位二维码
   - 当前货品相关二维码
4. 点击弹窗外区域或左上角关闭按钮可关闭。

### 3.2 选择打印二维码

1. 打开库位二维码弹窗后，每个码旁边都有选择框。
2. 默认所有码都勾选。
3. 不需要打印的码，取消勾选。
4. 点击左上角“打印”按钮。
5. 系统只打印已勾选的二维码。

## 4. 竖版异常处理

竖版处理按钮只有在库存查询结果里点击了大于 0 的库存数字后使用。

当前竖版按钮：
- 异位拣选
- 拣选无货
- 属性变更

### 4.1 异位拣选

使用场景：货在别的库位，需要从异位库位完成拣选，同时记录原始库位缺货。

操作步骤：
1. 先完成库存查询。
2. 在库存结果表格中，点击需要处理的可用库存或占用库存数字。
3. 点击竖版“异位拣选”。
4. 如果当前已有红色库位，红色库位就是原始拣选库位。
5. 如果系统还需要选择库位，按页面提示选择：
   - 异位拣选库位
   - 原始拣选库位
6. 输入拣选数量：
   - 1 到 5 可直接点按钮。
   - 大于 5 的数量在输入框里输入数字后回车。
7. 完成后系统生成记录。

系统记录内容：
- 处理类型：异位拣选
- SKU
- 异位拣选库位
- 异位拣选数量
- 原始拣选库位
- 原始拣选库位缺货数量
- 原始拣选库位可用库存
- 需要调减库位
- 需要调减数量
- 创建时间

规则：
- 异位拣选数量不能大于异位拣选库位的可用库存。
- 异位拣选数量等于原始拣选库位缺货数量。
- 需要调减库位默认为异位拣选库位。
- 需要调减数量等于异位拣选数量。
- 如果原始拣选库位仍有可用库存，系统会额外生成需要调减原始库位库存的记录。

### 4.2 拣选无货

使用场景：原始拣选库位无货，无法正常拣选。

操作步骤：
1. 先完成库存查询。
2. 在库存结果表格中，点击对应库位的可用库存或占用库存数字。
3. 点击竖版“拣选无货”。
4. 如果当前有红色库位，红色库位就是原始拣选库位。
5. 如果没有红色库位，刚才点击的数字所在库位就是原始拣选库位。
6. 页面显示“请选择缺货数量”。
7. 选择或输入缺货数量：
   - 1 到 5 可直接点按钮。
   - 大于 5 的数量在输入框里输入数字后回车。
8. 完成后系统生成记录。

系统记录内容：
- 处理类型：拣选无货
- SKU
- 原始拣选库位
- 原始拣选库位缺货数量
- 原始拣选库位可用库存
- 需要调减库位
- 需要调减数量
- 创建时间

规则：
- 如果原始拣选库位可用库存大于 0，则需要调减库位为原始拣选库位。
- 需要调减数量等于原始拣选库位可用库存。
- 如果原始拣选库位可用库存为 0，则不生成调减数量。

### 4.3 属性变更

使用场景：货品需要转残。

操作步骤：
1. 先完成库存查询。
2. 在库存结果表格中，点击对应库位的可用库存或占用库存数字。
3. 点击竖版“属性变更”。
4. 选择转残库位。
5. 页面显示“请选择转残数量”。
6. 选择或输入转残数量：
   - 1 到 5 可直接点按钮。
   - 大于 5 的数量在输入框里输入数字后回车。
7. 完成后系统生成记录。

转残库位排序规则：
1. 优先可用库存最多。
2. 可用库存相同时，占用库存少的排前面。

系统记录内容：
- 处理类型：属性变更
- SKU
- 货主名称
- 转残库位
- 转残数量
- 创建时间

## 5. 返回、取消、重置

### 5.1 返回

在竖版处理流程中，点击“返回”会回到上一步。

### 5.2 取消

在竖版处理流程中，点击“取消”会关闭当前处理任务，不写入记录。

### 5.3 重置

点击右侧“重置”会清空当前异常处理页面的输入和输出。

注意：
- 重置不会删除已经写入总表的异常记录。
- 已写入的记录以总表为准。

## 6. 横版明细查看

横版按钮用于查看已经生成的异常明细。

当前横版按钮：
- 异位拣选
- 拣选无货
- 属性变更

操作步骤：
1. 在顶部选择日期。
2. 选择白班或夜班。
3. 点击对应横版按钮。
4. 页面弹出明细窗口。
5. 弹窗左侧有：
   - 导出
   - 关闭

明细过滤规则：
- 明细数据来自异常处理总表。
- 选择日期和班次后，只显示对应班次时间范围内的记录。
- 默认白班为当日 04:00 到当日 17:30。
- 默认夜班为当日 17:30 到次日 04:00。
- 如修改班次设置，则按设置后的时间执行。

## 7. 班次设置

1. 点击顶部“班次设置”。
2. 设置白班开始时间和结束时间。
3. 设置夜班开始时间和结束时间。
4. 点击“确定”保存。
5. 点击“取消”放弃本次设置。

规则：
- 当日夜班 = 当日下午的夜班开始时间 到 次日凌晨的夜班结束时间。
- 横版明细和导出按当前设置的班次时间过滤。

## 8. 导出

### 8.1 导出总表

点击页面右侧“导出”，导出异常处理总表。

总表文件：
- `异常处理总表.csv`
- `异常处理总表.xls`

总表包含所有已写入的异常记录。

### 8.2 导出单类明细

1. 点击横版“异位拣选 / 拣选无货 / 属性变更”。
2. 在弹出的明细窗口中点击“导出”。
3. 导出的文件只包含当前日期、当前班次、当前处理类型的明细。

## 9. 清除缓存

管理员版可点击“清除缓存”。

清除内容：
- 产品图片缓存
- 二维码缓存
- WMS 拉取缓存
- 页面分析缓存

保留内容：
- 异常处理总表
- 班次设置

注意：
- 清除缓存不是删除异常记录。
- 如果只是想清空当前页面，使用“重置”。

## 10. 操作注意事项

1. 做异常记录前，先确认当前库存查询结果是正确 SKU 或正确条码。
2. 通过库位查询跳到库存查询时，红色库位代表当前原始库位。
3. 竖版异常处理必须先点击库存数字，再点击处理按钮。
4. 大于 0 的库存数字才可点击。
5. 异位拣选数量不能超过异位库位可用库存。
6. 拣选无货会按原始库位可用库存决定是否生成调减数据。
7. 属性变更会把货主名称写入总表；横版明细也从总表读取。
8. 总表是最终记录来源，不要随意删除或手改正在使用中的总表文件。
9. 如果页面显示不对，先刷新页面；如果仍不对，再使用清除缓存。
