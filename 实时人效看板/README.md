# 实时人效看板

本地拣选状态分析看板。

## 启动

双击后会启动一个脱离终端的本地服务进程，关闭终端后页面仍可继续使用。

双击：

`启动实时人效看板.command`

打开：

`http://127.0.0.1:5317`

## 状态口径

- 已分配：没有拣选开始时间
- 拣选中：有拣选开始时间，没有拣选完成时间
- 已拣选：拣选开始时间和拣选完成时间都有

## 文件导入

支持拖入 Excel，或点击打开文件 / 打开文件夹。

## 账号设备绑定

授权后台在 `license-worker/`，用 Cloudflare Workers + D1 免费方案。

基本顺序：

1. 进入 `license-worker/`，按里面的 `README.md` 部署 Cloudflare Worker。
2. 复制 `.license.env.example` 为 `.license.env`。
3. 把 `LICENSE_API_URL` 改成 Worker 发布后的地址。
4. 重启看板。

启用后，用户第一次登录会绑定当前设备；同一个账号换设备登录会被拒绝，并按后台配置锁定账号。

未创建 `.license.env` 时，本机仍按开发模式运行，不强制云端登录。
